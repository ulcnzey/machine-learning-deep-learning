# 01 - Machine Learning Basics

## Overview

This section introduces the fundamental concepts of Machine Learning (ML), starting from the basic principles and gradually moving toward how machine learning models learn from data.

The goal is not just to learn the terminology, but to understand how a machine learning model processes data, identifies patterns, makes predictions, and improves its performance.

## Learning Roadmap

The basic machine learning process can be summarized as follows:

```text
Data
  ↓
Features and Labels
  ↓
Machine Learning Model
  ↓
Prediction
  ↓
Loss Calculation
  ↓

  ↓

  ↓

```

## Learning Objective

By the end of this section, the reader should understand:

- What machine learning is and how it works.
- How data is represented in machine learning.
- The difference between features and labels.
- How a model learns from examples.
- Why training, validation, and test datasets are needed.
- What overfitting, underfitting, and generalization mean.
